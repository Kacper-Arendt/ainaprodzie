# Maister project skills

This directory includes the skills and supporting files from
[SkillPanel Maister Codex 2.2.3](https://github.com/SkillPanel/maister/tree/feat/codex-platform-support).
The original [MIT license](MAISTER-LICENSE) applies to the imported files.

In a Codex chat opened on this repository, use `$maister-work` to route a task,
or `$maister-init` to review or initialize project standards. Codex discovers
these skills from `.agents/skills`, including when this branch is checked out
in Codex Cloud. Maister can use a browser tool when the environment supplies one.

When updating the import, copy the full skill directories for the new version,
including their references and assets, and keep intra-Maister references in
the project form `$maister-<skill>`.
